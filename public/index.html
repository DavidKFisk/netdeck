      Run NetDeck as administrator

      A few command variants (such as netstat -anob) and Wi-Fi details on Windows 11 need administrator rights. Everything else works without them.

      
      
      
        
        
        
      
      
    
      
  
      

  
      
    
      
      
      Connect a local NetDeck
      
      
      A web page can't run commands on your computer by itself. Start the NetDeck server on this machine with this site as its allowed origin, then enter the pairing token it prints:
      
      
      NETDECK_ORIGIN=<this site> node server.js
