      Add a command

      Custom commands appear as reference cards with copy buttons. They never get a run button — only the built-in, vetted commands can execute.

      Run NetDeck as administrator

      A few command variants (such as netstat -anob) and Wi-Fi details on Windows 11 need administrator rights. Everything else works without them.

      Scheduled playbooks
      
      
      Run a playbook every few minutes while NetDeck is open. Each run opens a tab; unchanged runs replace the previous one, and a run whose result changed (a new device, a verdict that flipped, a step that started failing) is kept, marked with "!" and, if you like, announced with a notification. Schedules are remembered and resume when NetDeck is reopened.

        Connect a local NetDeck
        
      
        A web page can't run commands on your computer by itself. Start the NetDeck server on this machine with this site as its allowed origin, then enter the pairing token it prints:
        
      
        NETDECK_ORIGIN=<this site> node server.js
